# RiverIQ — run it

```
npm install
npm run dev
```

Open the URL it prints (usually http://localhost:5173). That's it.

Requires Node.js 18+ (you already have it if Claude Code runs).

To put it on the internet later: `npm run build`, then drag the `dist/`
folder into Netlify, or push the project to GitHub and import it in Vercel.
